Gambit · jade / noir 色彩系統

完整 token 對照（恆顯雙欄）＋ 6 個代表頁面 mockup（隨主題切換）。noir 邏輯＝把設計系統既有的「deep-jade 暗區配色」推到全 app、base 移到中性暖黑、jade 當品牌家族穿進 nav／學習／focus；金維持唯一高光。棋盤木質兩主題暫共用（之後做使用者可換）。

A · Token 盤點（jade ↔ noir 對照）

A‑2 · nav 配色：深錨（現行）vs 跟隨 primary（你預期的）

深 nav 是既有設計系統，非 council：nav＝deep-jade 錨（與沉浸區同色「世界的框」），刻意比 primary 動作色深。它在 cream 對（亮底壓暗錨、對比強），在 noir 是弱點（暗底壓暗 nav、浮不出來）。
三選一：A＝深 jade 兩主題（noir 靠 hairline 勉強浮）；A′（推薦）＝暗色主題慣例「抬起」——noir nav 比 base 亮一階（jade 抬起條 #1A2620 + glass 頂光），靠 elevation 浮、維持安靜 jade，選中那格才用 primary jade（你要的「跟隨 primary」收斂在 active tab）；B＝整條 primary jade（最亮最搶、打破「nav＝沉浸錨同色」一致性、對平靜北極星偏吵）。cream 三者差別小（深 nav 本來就對），差異主要在 noir。

B · 現有頁面 Mockup（切上方主題對照）

讀法：奶油主題＝現行上線樣貌；切 noir 看同一批頁面在第二主題下整體協不協調。重點觀察——① 深 jade 沉浸區（對局/課程/試煉/棋誌）在 noir 變成 jade-黑、靠 glass + 漸層分層；② 主按鈕 jade 不再孤立（nav/學習/coach 頭像都帶 jade 家族）；③ 金只在 reward/CTA/focus 出現，維持唯一亮點。

Council 修正（已套入）：base 改暖暮色 #141110 ＋ 暖棕陰影（守設計系統「永不純黑」鐵則，並讓切換像「調暗同一房間」而非換 app）；主按鈕 #226B55／近白字＝過 WCAG AA ≈6:1（原 #2A8268 只有 4.41:1）；ink-faint 提到 #8A8478 讓鎖定標籤/時戳過 AA。

兩條 noir 專屬護欄（待寫進設計系統）：① 金仍只給 reward/eval/focus——near-black 上金字對比變好（11:1），天然「醜到只能當高光」的護欄消失，必須明文守住、別讓金滲進 eyebrow/數字。② 沉浸區靠 elevation/glass/漸層分層，不只靠色相——deep #0F1E17 vs base 亮度近似，單靠色相在手機日光下會消失。

實作排序（Pragmatist）：先上 [data-theme="noir"] token override（單檔、低風險、~70% 可重用既有 on-deep 詞彙）；深區頁面有 ~30 個寫死漸層 hex 在 component 內（木盤/地城幣/英雄卡），翻不到 token，隨頁面上線再逐步 tokenize，別為還沒人用的主題先做全域 sweep。拍板後寫進 design/gambit-design-system/ 當官方 noir theme。
