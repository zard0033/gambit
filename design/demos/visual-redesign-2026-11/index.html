Gambit 視覺重構樣張（第 0 波）

三份樣張各畫 7 個手機畫面（390×844）。報告在 production/visual-review-2026-11-17.md，方向說明在第 8 節。要用 npm run dev 開這一頁，字型與棋子才載得到；直接點兩下開檔案會掉字型。

  • 先看這頁：現況與三個方向並排七個畫面，每列「現況｜地基｜B｜C」。要你決定的事在同目錄 decisions.md。
  • 地基：只把現有的語彙收齊不加新東西，只收齊骨架。這層不管選哪個方向都要做。
  • B 棋境一景地基之上加一幅畫：夜裡一張木棋桌的一角。
  • C 木、紙、墨地基之上不加插圖，放大墨筆與棋子印章，同時做減法。

三份都是第二版（各照審查評語修過一輪）。Windows 上的字重和 iPhone 實機有落差，最後要在手機上再看一次。
