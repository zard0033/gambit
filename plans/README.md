## Direction findings

Options for the maintainer to weigh, not problems ranked against bugs. Effort
estimates here are coarser than in the table above.

**D-01 — Close the decoy gap on the one differentiating loop.**
`src/modules/learning-loop/recognition-runtime.ts:25` builds every own-game drill
board as `kind: 'real'` (its own file header at `:3` says so). The curated set at
`src/data/concept-deepening/recognition.ts:30` *does* ship `kind: 'decoy'` boards.
`README.md:51` advertises own-game drills "mixed with decoys that don't announce
whether there's an answer" — that claim is not true of the only code path that
builds them, and `production/positioning-v2-2026-08-02.md:21` already names the
gap. Trade-off: a same-game decoy needs either new selection logic (a plausible-
looking but non-tactical position from the player's own game) or a type/UX change
admitting curated decoys into an own-game set; either way it goes through the
three-gate content pipeline in `.claude/docs/chess-content-guardrails.md`. Effort
M/L. **The cheap half of this is free**: correct the README claim now, and treat
the decoy gap as a named gap rather than a shipped feature.

**D-02 — One forward-looking detector unblocks three separately-tracked items.**
`src/modules/learning-loop/classify.ts:57-60` (`hungUndefendedMaterial`) already
has the attacker/defender/recapture-value logic, but its signature takes
`opponentReplyUci` — it is post-hoc by construction. Three stated-but-undelivered
items all wait on the forward-looking inverse of it: 判斷訓練's material half
(`positioning-v2:129` explicitly says `classify.ts:57-92` cannot be reused),
hanging-piece naming (`src/modules/memory/describe.ts:65-66`, a standing
`ponytail:` marker), and the mate→material extension of missed-mate
(`active.md:123-125`, positioning-v2's P2). Trade-off: enumerating all legal moves
is a much larger false-positive surface than checking one played reply, and
`classify.ts` is deliberately conservative ("prefer-silence", `:55`). Effort M.

**D-03 — Game export is one-directional.** `src/config/export-tuning.ts:33-38`
asks the AI to "point out one or two recurring habits" and "suggest one specific
thing to study or practice next", but there is no path for that answer to come
back: the only `loadPgn` call in `src/` is
`src/modules/memory/history-game.ts:18`, replaying a game's own stored PGN.
`positioning-v2:177` records "把你的棋帶出去跟 AI 討論" as a kept product goal.
Trade-off: this sits **outside** the 斷層/察覺 thesis — it does not train
recognition — so it competes with the core loop for attention. ADR-0010 is silent
on a return path rather than opposed to one. Effort S/M for a paste-back note
field; L for anything auto-parsed.

**D-04 — The "該殺沒殺" signal already has its pipe built and idle, on a clock.**
`active.md:107` names mate-distance as the wanted third signal (cpLoss is
insensitive to mate). `src/types/memory.ts:22-24` records that `MemoryGameSummary`
has had zero readers since D4 and carries a review-by date of 2026-11-06 — it is
written every game for free. Trade-off: the schema shape is unspecified anywhere;
and this depends on D-02 existing first if the signal is to cover material as well
as mate. Effort M.
